# גשר טלגרם <-> מייל

שירות קטן שמחבר בין בוט טלגרם שלך לבין תיבת המייל של הסוכן:
אתה כותב לבוט בטלגרם -> השירות שולח מייל מהג'ימייל שלך אל `arielgolan@mail.instinct.com`
(עם סימון האמון בתחילת ההודעה) -> התשובות שחוזרות לג'ימייל נדחפות חזרה לטלגרם.

## איך זה עובד

- **טלגרם -> מייל:** webhook של טלגרם פוגע ב-Render, והשירות שולח מייל דרך SMTP של ג'ימייל עם App Password. כל ההודעות יושבות על אותו נושא ("Telegram Bridge") עם Re:/In-Reply-To, כך שהסוכן רואה שרשור אחד.
- **מייל -> טלגרם:** ת'רד רקע סורק את הג'ימייל ב-IMAP כל 60 שניות אחר מיילים מ-`arielgolan@mail.instinct.com` ומעביר לטלגרם רק מיילים חדשים (הוא זוכר את ה-UID האחרון). בהפעלה ראשונה הוא מדלג על כל ההיסטוריה ומתחיל מהמייל האחרון.
- **בוט פתוח:** כל אחד שכותב לבוט מגשר למייל. אבל רק ההודעות מהצ'אט שלך (`TELEGRAM_CHAT_ID`) מתחילות בסימון האמון (הערך הסודי שמוגדר ב-`TRUST_MARKER`) ומקבלות אמון מלא אצל הסוכן. הודעות מאחרים מועברות בלי הסימון, עם תווית שולח, על שרשור נפרד (`Telegram Bridge (chat <id>)`), והתשובות חוזרות לאותו צ'אט בלבד.

## שלב 1 - ליצור בוט אצל BotFather

1. פתח בטלגרם את `@BotFather` ושלח `/newbot`.
2. תן שם ושם משתמש (חייב להסתיים ב-`bot`).
3. BotFather יחזיר **טוקן** שנראה כך: `1234567890:AA...` - שמור אותו. זה `TELEGRAM_BOT_TOKEN`.

## שלב 2 - למצוא את ה-chat ID שלך

1. שלח הודעה כלשהי לבוט החדש (למשל "היי").
2. פתח בדפדפן: `https://api.telegram.org/bot<הטוקן>/getUpdates`
3. חפש בתשובה `"chat":{"id":` - המספר שם הוא `TELEGRAM_CHAT_ID` שלך.

## שלב 3 - App Password לג'ימייל

1. כנס ל-`myaccount.google.com` עם החשבון `boherbatov@gmail.com`.
2. **אבטחה** -> ודא ש**אימות דו-שלבי** מופעל (חובה).
3. חפש למעלה "סיסמאות אפליקציה" (App passwords).
4. צור סיסמה בשם `Telegram Bridge` והעתק את 16 התווים. זה `GMAIL_APP_PASSWORD`.

## שלב 4 - העלאה לגיטהאב

1. צור ריפו **פרטי** חדש (למשל `telegram-bridge`).
2. Add file -> Upload files -> גרור את כל הקבצים מהתיקייה הזו (`app.py`, `requirements.txt`, `README.md`).
3. Commit.

## שלב 5 - פריסה ב-Render

1. Render -> **New** -> **Web Service** -> חבר את הריפו.
2. Runtime: **Python 3**. Build Command: `pip install -r requirements.txt`. Start Command: `gunicorn app:app --timeout 120`. Plan: **Free**.
3. ב-**Environment** הוסף:

   | משתנה | ערך |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | הטוקן מ-BotFather |
   | `TELEGRAM_CHAT_ID` | המספר משלב 2 - אופציונלי אבל מומלץ; בלעדיו אף אחד לא מקבל את סימון האמון |
   | `GMAIL_ADDRESS` | `boherbatov@gmail.com` |
   | `GMAIL_APP_PASSWORD` | סיסמת האפליקציה משלב 3 |
   | `WEBHOOK_SECRET` | מחרוזת אקראית שתבחר (משמשת רק להגדרת ה-webhook) |

   אופציונלי: `AGENT_EMAIL` (ברירת מחדל `arielgolan@mail.instinct.com`), `TRUST_MARKER` (הביטוי הסודי שלך לאמון - בלי ברירת מחדל; בלעדיו ההודעות שלך מגיעות בלי אמון), `POLL_INTERVAL` (ברירת מחדל 60 שניות).

4. Deploy. בסוף תקבל כתובת כמו `https://telegram-bridge-xxxx.onrender.com`.

## שלב 6 - לחבר את ה-webhook

פתח בדפדפן:

```
https://<הכתובת-שלך>.onrender.com/set-webhook?secret=<WEBHOOK_SECRET>
```

אמור להופיע `{"ok":true,...}`. מרגע זה הבוט חי.

## שלב 7 - keep-alive (חשוב!)

Render Free **נרדם** אחרי רבע שעה בלי תנועה, ואז הסריקה של הג'ימייל עוצרת. פתרון חינמי:

1. הירשם ל-`cron-job.org` (חינם).
2. צור job שפונה כל **5 דקות** אל `https://<הכתובת-שלך>.onrender.com/health`.

זה שומר על השירות ער.

## בדיקה

פתח `https://<הכתובת-שלך>.onrender.com/selftest?secret=<WEBHOOK_SECRET>` - אמור להחזיר `ok` עבור imap, smtp ו-telegram. אם משהו `fail`, כנראה שמשתנה סביבה שגוי (בדרך כלל ה-App Password).

אחר כך שלח לבוט "בדיקה" - אמור לחזור "✅ נשלח" ובתיבת boherbatov יצא מייל לסוכן עם הנושא "Telegram Bridge". כשהסוכן עונה, התשובה מופיעה בטלגרם תוך עד דקה.

## הערות

- קובץ המצב (`bridge_state.json`) יושב על הדיסק הזמני של Render - אחרי redeploy הוא מתאפס, והשירות פשוט מתחיל שוב מהמייל האחרון (לא שולח כפילויות של היסטוריה).
- כרגע טקסט בלבד; תמונות/קבצים מהטלגרם לא מועברים.
- אל תמחק את סימון האמון מתחילת המיילים - בלעדיו הסוכן מתייחס למייל לפי הכלל הישן (דורש אישור בווטסאפ).
- הבוט פתוח לכולם: שים לב למי אתה נותן את שם הבוט. אורחים לא מקבלים את סימון האמון, אבל כן יכולים לשלוח מיילים דרך הגשר ולראות תשובות בשרשור שלהם.
